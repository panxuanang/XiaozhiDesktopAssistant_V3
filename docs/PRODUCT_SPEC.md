# 产品规格：小智打工人搭子 V0.3

## 一句话定位

**人不想坐在电脑前时，让小智替你把工作接住、处理、汇报、按时交差。**

## 目标用户
- 日常大量使用微信、Excel、Word、网页的办公室用户
- 周末/下班后仍可能收到临时工作的打工人
- 小团队负责人、销售、运营、行政、店长

## 核心体验
1. 语音查看重要联系人工作消息
2. 自动关联工作附件
3. 本地优先完成 Excel/文件/网页处理（含拆表、批处理、多来源联网调研）
4. 需要语言能力时调用用户自选 API
5. 结果回报
6. 明确授权后定时微信交付

## 产品差异化
不是“再做一个桌面 Agent”，而是：
- 语音入口
- 不要求用户坐在电脑前
- 本地优先，减少 API 成本
- 微信工作流
- 任务中心和定时交付
- 重复任务上下文“照旧”

## 默认安全边界
- 发微信：先确认
- 定时发微信：入队前明确授权
- 删除：确认
- 命令：确认
- 支付/下单：不做无确认自动化
- AI 不直接执行任意代码；Excel AI 规划限制在操作白名单

## V0.3 验收标准
- 无 API Key 也能使用全部本地能力
- 小智 MCP 默认只暴露高层工具
- 周末老板场景全链路可在目标 Windows/微信版本跑通
- 定时发送掉线/睡眠后有可解释结果
- 所有云调用由用户自己配置供应商


## V0.3 新增核心工作流
- “网上查资料 → 多来源提炼 → Word 报告 → 微信交付”
- “一个 Excel 按列拆几十份”
- “一个文件夹几十个 Excel 做同样处理”
- “两张表按关键字段匹配补数据”
- “复杂重复 Excel 工作先生成受限计划，再本地批量执行”
