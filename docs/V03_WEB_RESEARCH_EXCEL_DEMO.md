# V0.3.0 真机演示脚本

## A. 多来源联网调研

口令：
> 小智，网上查一下最近 AI 眼镜行业的发展情况，找 5 个不同来源，整理成一份 Word 报告发我微信。

预期：
1. Chrome/Edge 本地搜索。
2. 收集多个不同来源并逐页读取。
3. 每页先本地压缩。
4. 有 API 时只在最终综合阶段调用一次；无 API 时生成本地来源汇编报告。
5. 生成 Word。
6. 准备发到“文件传输助手”。
7. 语音确认后发送。

## B. Excel 按列拆多个文件

口令：
> 小智，把桌面的销售明细.xlsx 按部门不同值拆成多个小表格，每个部门一个 Excel。

预期：生成 `销售明细_按部门拆分/`，每个部门一个 `.xlsx`，同时生成 `拆分清单.xlsx`。全程 0 API。

## C. 同一 Excel 拆多个 Sheet

口令：
> 按区域拆开，但放在同一个 Excel 的不同工作表里。

预期：生成 `*_按区域拆分.xlsx`，包含区域 Sheet + `拆分清单`。

## D. 批量重复处理

口令：
> 小智，把 D:\月报 这个文件夹所有 Excel 按订单号去重，再计算每行金额和税额的合计。

预期：处理计划只规划一次，随后本地批量处理全部文件，并输出到 `小智批量处理结果/`。

## E. 两表匹配

口令（建议先用 desktop_agent/低层工具真机验证）：
> 把订单表.xlsx 和客户表.xlsx 按客户ID匹配，把客户名称补到订单表。

预期：本地 pandas merge 生成 `订单表_匹配结果.xlsx`。

## 注意
- 复杂 `.xlsm` / Power Query / 数据透视表 / 外部链接必须用真实客户模板回归测试。
- 微信发送仍要求确认。
- 搜索引擎页面结构会变化，商业发布前要在 Bing/百度/Google 分别真机测试。
