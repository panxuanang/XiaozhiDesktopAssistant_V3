# V0.3.2 执行能力回归修复

V0.3.1 为了减少小智朗读过多内容，把 `desktop_agent` 和大量低层工具一起隐藏到了 `expose_low_level_tools` 开关后面。默认该开关为 false，某些没有被 `workmate` 规则直接匹配的语音任务会退化成只回答、不执行。

V0.3.2 修复方式：

- `workmate` 继续作为本地优先主入口；
- `desktop_agent` 作为 **单个高层兜底工具** 在普通模式始终可见；
- 文件/Office/浏览器/UIA/微信等几十个低层工具仍然默认隐藏，不增加 MCP schema 体积；
- `desktop_agent` 仍经过 V0.3.1 的精简语音策略，因此恢复执行能力，不恢复“打开网页后念一大段”的问题。

## 微信文件发送说明

当前微信发送文件并不是固定坐标点鼠标。底层方案是：

1. UIA 激活微信窗口；
2. `Ctrl+F` 搜联系人，剪贴板粘贴联系人名称，Enter 进入会话；
3. 使用 Windows `CF_HDROP` 把文件放入系统剪贴板；
4. `Ctrl+V` 粘贴文件到聊天框；
5. Enter 发送；
6. UIA 尝试验证文件名是否出现在会话。

后续版本可以再增加“UIA 定位聊天输入框 -> 点击控件中心 -> 再粘贴”的兜底，适配微信版本差异。
